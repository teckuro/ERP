# Modulo Nomina mensual – guia general

## Objetivo

Gestionar el proceso mensual de remuneraciones, incluyendo prevalidaciones por periodo y la integracion futura del motor de calculo. 
Actualmente se encuentra en una fase inicial que documenta el contrato funcional y las prevalidaciones.

## Alcance

- Seleccion del periodo `YYYY-MM` para el proceso mensual.
- Ejecucion de prevalidaciones que verifican la consistencia de parametros, empleados, conceptos y movimientos variables.
- Presentacion de resultados de prevalidaciones en paneles de estado (bloqueos, advertencias, informacion).
- No incluye calculo de montos, generacion de liquidaciones ni exportes a Previred/LRE (fases futuras).
