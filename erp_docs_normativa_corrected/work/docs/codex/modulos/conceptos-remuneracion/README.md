# Modulo Conceptos de remuneracion – guia general

## Objetivo

Gestionar el catalogo maestro de conceptos de remuneracion. 
Los conceptos definen como se calcula y clasifica cada remuneracion, y son utilizados por los modulos de Haberes, Movimientos variables y Proceso mensual.

## Alcance

- Diagnostico del estado actual del catalogo.
- Reglas de negocio para el mantenimiento de conceptos.
- Decisiones operativas y modelo funcional.
- No incluye el calculo de liquidaciones ni la asignacion en Haberes (ver `haberes-descuentos/contrato-general.md`).
