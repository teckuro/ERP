# Documentación normativa

Este subdirectorio agrupa toda la normativa chilena relacionada con remuneraciones de forma modular.  Cada archivo aborda un tema específico — por ejemplo, ingreso mínimo mensual o gratificación legal — y permite que otros módulos hagan referencia directa a las reglas que necesitan.

Para un panorama general del marco legal consulte el índice en `normativa‑remuneraciones.md`.  Para implementar reglas operativas en el ERP utilice la matriz normativa operativa que se define en `matriz‑normativa‑operativa.md`.
