# Orquestador – contexto y fases del proyecto

## Objetivo

El orquestador define el contexto global del proyecto, la estructura operativa, las fases de desarrollo y las dependencias entre ellas. Centraliza la planificacion para que todos los actores conozcan el estado y la prioridad de cada modulo.

## Contenido

- **contexto-proyecto.md** – descripcion del producto, su alcance y las restricciones.
- **diseno-operativo-erp.md** – explica la arquitectura operativa, la separacion de dominios y la estrategia de fases.
- **estado-fases.md** – tablero vivo que indica que fases estan cerradas, en desarrollo o pendientes.
- **dependencias-fases.md** – define las dependencias entre fases y modulos.
- **roadmap-operativo.md** – cronograma operativo y prioridades.
- **matriz-roles-permisos.md** – define roles de usuario y permisos a nivel del sistema (pendiente de implementacion de RLS/JWT).
- **mapa-documentacion.md** – mapa de archivos y su proposito.
- **criterios-cierre-fases.md** – criterios que deben cumplirse para declarar una fase cerrada.

## Lectura recomendada

1. Lea `contexto-proyecto.md` para entender la vision del producto.
2. Revise `diseno-operativo-erp.md` y `dependencias-fases.md` para conocer como se organizan los equipos y las funcionalidades.
3. Consulte `estado-fases.md` para ver el avance actual.
4. Revise `roadmap-operativo.md` para conocer las proximas fases y su prioridad.
