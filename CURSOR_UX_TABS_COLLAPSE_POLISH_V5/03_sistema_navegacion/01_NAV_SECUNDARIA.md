# 01_NAV_SECUNDARIA

## Niveles de navegacion

### Nivel 1 - Sidebar

Modulos principales:

```txt
Dashboard
Empleados
Remuneraciones
Licencias Medicas
Reportes
Parametros
```

### Nivel 2 - Remuneraciones

Flujo operativo:

```txt
Preparar nomina
Liquidaciones oficiales
Movimientos del mes
Asignaciones recurrentes
Conceptos de remuneracion
```

### Nivel 3 - Tabs internos

Solo dentro de pantalla:

```txt
Todas / Emitidas / Aprobadas
Disponibles / Futuras
Resumen / Detalle / Observaciones, si corresponde
```

## Regla

No usar tabs para navegar entre modulos.

## Breadcrumb

Debe mostrar contexto, no repetir todo:

```txt
Remuneraciones / Preparar nomina
Remuneraciones / Liquidaciones oficiales
```

## Header

Debe tener accion principal, no 4 botones con mismo peso.
