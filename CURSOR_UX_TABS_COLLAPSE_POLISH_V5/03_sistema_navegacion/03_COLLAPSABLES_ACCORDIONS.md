# 03_COLLAPSABLES_ACCORDIONS

## Cuándo usar collapsable

Usar para contenido secundario:

```txt
detalle tecnico
observaciones
filtros avanzados
salidas futuras
historial
ayuda contextual extensa
```

## No usar para

```txt
estado principal
siguiente accion
bloqueos criticos
CTA principal
```

## Visual

```txt
header compacto 40-48px
chevron a la derecha
estado/counter opcional
contenido con padding moderado
sin scroll horizontal interno
```

## Accesibilidad

```txt
button para header
aria-expanded
aria-controls
id de panel
Enter/Space abre/cierra
focus visible
```

## En el ERP

Preparar nomina:

```txt
Detalle tecnico -> collapsable
Checklist largo -> collapsable si no bloquea
Observaciones informativas -> collapsable
```

Liquidaciones:

```txt
Alcance/fuera de alcance -> collapsable compacto
Detalle tecnico -> collapsable
Bloqueos informativos no criticos -> collapsable
```

Dashboard/Reportes:

```txt
Salidas futuras -> collapsable/lista compacta
```
