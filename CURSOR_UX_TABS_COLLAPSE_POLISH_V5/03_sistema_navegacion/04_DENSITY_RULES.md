# 04_DENSITY_RULES

## Objetivo

Reducir espacio sin perder legibilidad.

## Alturas maximas recomendadas

```txt
page header: 72-96px
status strip: 44-64px
metric card: 64-84px
quick link: 48-64px
accordion header: 40-48px
empty state: 140-200px
```

## Si una seccion supera 220px sin datos

Revisar. Probablemente debe ser:

```txt
notice
empty compacto
collapsable
lista compacta
```

## Grid recomendado

Dashboard:

```txt
main 2 columnas solo si ambos lados tienen contenido real
si no, una columna con listas compactas
```

Preparar nomina:

```txt
summary 2/3 + next action 1/3
timeline full width compacto
bloqueos y checklist en dos columnas solo si tienen contenido
```

Liquidaciones no disponible:

```txt
estado + accion
resumen compacto
no tabla alta si no hay registros
```

## Texto

```txt
subtitulos max 1-2 lineas
descripciones de cards max 2 lineas
```
