# 01_REFERENCIAS_PATRONES

## Fuentes usadas

### WAI-ARIA APG - Tabs

Idea clave:

```txt
Los tabs son controles dentro de un tablist que muestran un tabpanel asociado.
Deben tener roles y navegacion de teclado correcta.
```

URL:

```txt
https://www.w3.org/WAI/ARIA/apg/patterns/tabs/
```

### WAI-ARIA APG - Accordion

Idea clave:

```txt
Un accordion es un conjunto de encabezados interactivos que expanden/colapsan secciones.
Enter o Space deben expandir/colapsar.
```

URL:

```txt
https://www.w3.org/WAI/ARIA/apg/patterns/accordion/
```

### Material Design 3 - Tabs

Idea clave:

```txt
Tabs organizan contenido entre pantallas, datasets u otras interacciones relacionadas.
Sirven para agrupar contenido en categorias utiles.
```

URL:

```txt
https://m3.material.io/components/tabs/guidelines
```

### Carbon Design System - Tabs

Idea clave:

```txt
Line tabs dentro de un componente deben alinear el primer label con el contenido.
No usar contained tabs dentro de componentes.
```

URL:

```txt
https://carbondesignsystem.com/components/tabs/usage/
```

### Carbon Design System - Accordion

Idea clave:

```txt
El contenido de un accordion no debe tener scroll horizontal.
Si el contenido supera el viewport, debe scrollear el conjunto, no un panel interno.
```

URL:

```txt
https://carbondesignsystem.com/components/accordion/usage/
```

## Traduccion al ERP

```txt
Tabs:
- parametros internos
- vistas hermanas dentro de misma pantalla
- estados equivalentes

Accordion:
- detalle tecnico
- observaciones
- salidas futuras
- secciones secundarias
- filtros avanzados

Quick links:
- ir a otra pantalla
- accesos implementados
- dashboard

Cards:
- metricas
- resumen de estado
- no navegacion principal

Action panel:
- siguiente accion recomendada
```
