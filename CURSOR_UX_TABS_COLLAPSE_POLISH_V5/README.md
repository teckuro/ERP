# CURSOR_UX_TABS_COLLAPSE_POLISH_V5

Carpeta unica para mejorar en serio:

```txt
tabs
tabbars
collapsables
accordions
quick links
densidad vertical
jerarquia de acciones
navegacion secundaria
```

## Problema actual

El sistema mejoro en contenido, pero algunas pantallas:

```txt
ocupan demasiado espacio
parecen tener tabs, cards y accesos mezclados
no siempre dejan claro que es pestaña, que es accion y que es resumen
tienen empty states utiles pero altos
usan muchas cajas para contenido de baja densidad
```

## Objetivo V5

Crear un criterio profesional para decidir:

```txt
cuando usar tabs
cuando usar accordion/collapsible
cuando usar quick links
cuando usar timeline compacto
cuando usar cards metricas
cuando usar action panel
cuando ocultar detalle tecnico
```

## Regla

No hacer rediseño artistico. Hacer sistema estable.

```txt
Menos cajas.
Mas jerarquia.
Tabs reales.
Collapsables utiles.
Acciones visibles.
Detalle escondido hasta que aporte.
```
