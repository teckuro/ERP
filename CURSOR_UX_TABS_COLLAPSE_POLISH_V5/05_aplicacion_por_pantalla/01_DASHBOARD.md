# DASHBOARD - Aplicacion V5

## Problema actual

Demasiadas cards/accesos con altura.

## Cambios

### 1. Status strip

Arriba:

```txt
Periodo Mayo 2026 · Siguiente accion: Preparar nomina
[Ir a preparar nomina]
```

### 2. Flujo validado compacto

No cards grandes. Usar quick link list o timeline compacto.

```txt
Preparar nomina
Liquidaciones oficiales
Movimientos del mes
Asignaciones recurrentes
Empleados
Parametros
```

### 3. Salidas futuras

Usar `FutureList` compacto:

```txt
Previred - Fase posterior
Libro de remuneraciones - Fase posterior
Archivo banco - Fase posterior
Centralizacion contable - Fase posterior
```

### 4. Collapsable opcional

Si la lista futura es larga, ponerla en accordion:

```txt
Salidas futuras no disponibles (4)
```

## No hacer

No volver a poner botones activos de reportes legales.
