# LIQUIDACIONES OFICIALES - Aplicacion V5

## Problema actual

Cuando no esta disponible, hay muchos bloques para decir que no hay nomina cerrada.

## Cambios

### 1. Estado no disponible compacto

```txt
No hay nomina cerrada disponible.
Para generar liquidaciones, primero cierra operativamente la nomina.
[Preparar nomina]
```

### 2. Ocultar resumen de ceros

No mostrar 4 metric cards con cero si no hay liquidacion.

Usar:

```txt
Resumen: sin generar
```

### 3. Tabla vacia compacta

No tabla alta si no hay trabajadores.

### 4. Alcance como collapsable

```txt
Que incluye y que no incluye esta pantalla
```

Dentro:

```txt
No genera PDF, firma, envio, Previred, LRE, banco ni contabilidad.
```
