# REPORTES - Aplicacion V5

## Problema actual

Muchas cajas en disponible/no disponible.

## Cambios

### Opcion A - Tabs reales

Si se mantiene en una sola pantalla:

```txt
[Disponibles] [No disponible en esta fase]
```

Usar tabbar real.

### Opcion B - Dos columnas compactas

```txt
Consultas disponibles
Salidas futuras bloqueadas
```

La lista de no disponible debe ser compacta.

## Recomendacion

Usar tabbar si Cursor puede hacerlo rapido y accesible.

Si no, usar dos columnas compactas.
