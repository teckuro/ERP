# Base

- `v11/run_all.sql`: indice ordenado para levantar la BD por partes.
- `v11/crear_sql_v6_11_integrada.sql`: esquema vigente completo en un unico archivo.
- `patches/`: parches puntuales de estructura o funciones.
- `historico/`: versiones anteriores de esquema. No usarlas para nuevas instalaciones.

Si se levanta una BD nueva, partir por `v11/run_all.sql`.
