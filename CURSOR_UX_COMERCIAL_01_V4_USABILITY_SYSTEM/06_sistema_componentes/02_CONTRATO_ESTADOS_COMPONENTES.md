# 02_CONTRATO_ESTADOS_COMPONENTES

## Tones

```txt
neutral
info
success
warning
danger
locked
future
```

## Uso

```txt
success: cerrado, generado, apto
warning: advertencias no bloqueantes
danger: bloqueo
locked: accion no disponible por estado
future: funcionalidad futura
info: ayuda contextual
```

## Estados con icono + texto

No depender solo de color.

Cada badge debe tener label textual.
