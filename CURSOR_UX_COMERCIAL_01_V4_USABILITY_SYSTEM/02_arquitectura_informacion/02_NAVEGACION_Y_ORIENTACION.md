# 02_NAVEGACION_Y_ORIENTACION

## Header global

Debe mantener:

```txt
Periodo activo
Usuario
Sesion
Accion cerrar sesion
```

Pero debe evitar:

```txt
selectores vacios
iconos sin significado
espacios muertos
```

## Sidebar

Cada item debe tener:

```txt
label claro
descripcion breve solo si aporta
estado activo evidente
```

## Descripciones recomendadas

```txt
Preparar nomina - Estado, pendientes y cierre
Liquidaciones oficiales - Salida interna desde nomina cerrada
Movimientos del mes - Bonos, descuentos y hechos del periodo
Asignaciones recurrentes - Montos que se repiten por trabajador
Conceptos de remuneracion - Catalogo de haberes y descuentos
```

## Contexto por pantalla

Arriba de cada pantalla:

```txt
que es
para que sirve
que periodo usa
```
