# 01_ARQUITECTURA_INFORMACION

## Navegacion objetivo

Menu principal:

```txt
Dashboard
Empleados
Remuneraciones
  Preparar nomina
  Movimientos del mes
  Asignaciones recurrentes
  Conceptos de remuneracion
  Liquidaciones oficiales
Licencias medicas
Reportes
Parametros
```

## Regla

Separar presente de futuro.

No mostrar como menu principal activo:

```txt
Previred
LRE
Banco
Contabilidad
PDF
Firma
Envio
```

mientras no existan.

## Orden mental

```txt
Preparar nomina = centro del proceso
Movimientos/asignaciones = entradas
Conceptos = catalogo
Liquidaciones = salida interna
Reportes = futura salida externa/control
```

## Breadcrumbs

Usar:

```txt
Remuneraciones / Preparar nomina
Remuneraciones / Liquidaciones oficiales
Remuneraciones / Liquidaciones oficiales / Detalle
```

No usar rutas tecnicas.

## Dashboard

Debe ser vista de salud del periodo, no menu de reportes legales.
