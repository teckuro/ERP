# 01_ACCESIBILIDAD_RESPONSIVE

## Accesibilidad minima

```txt
[ ] Contraste suficiente.
[ ] No depender solo de color.
[ ] Botones con texto claro.
[ ] Iconos con label/aria si corresponde.
[ ] Orden de headings logico.
[ ] Focus visible.
[ ] Empty states con heading claro.
[ ] Tablas con headers.
[ ] Botones deshabilitados con motivo visible cercano.
```

## Responsive

Desktop:

```txt
contenido + panel lateral
```

Tablet:

```txt
panel baja bajo resumen
```

Mobile:

```txt
una columna
acciones arriba
cards apiladas
tablas con scroll o cards resumen
```

## Teclado

Acciones clave deben ser alcanzables con teclado.

## Semantica

No usar solo divs clickeables si debe ser button/link.
