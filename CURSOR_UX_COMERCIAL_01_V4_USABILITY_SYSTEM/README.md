# CURSOR_UX_COMERCIAL_01_V4_USABILITY_SYSTEM

Version V4 enfocada en usabilidad profunda.

Esta carpeta reemplaza el enfoque "mejorar visualmente" por un enfoque de producto:

```txt
arquitectura de informacion
modelo mental del usuario
jobs-to-be-done
flujos de tarea
patrones de interaccion
estados y transiciones
prevencion de errores
empty states accionables
tablas y densidad de datos
accesibilidad y responsive
scorecard profesional
tickets atomicos para Cursor
```

## Como usar

1. Copiar esta carpeta en la raiz del repo.
2. Abrir primero:

```txt
CURSOR_UX_COMERCIAL_01_V4_USABILITY_SYSTEM/00_runbook/00_EJECUTAR_CURSOR.md
```

3. Ejecutar tickets de:

```txt
CURSOR_UX_COMERCIAL_01_V4_USABILITY_SYSTEM/09_backlog_tickets/
```

4. Validar con:

```txt
CURSOR_UX_COMERCIAL_01_V4_USABILITY_SYSTEM/10_qa_scorecard/
```

## Principio

No hacer solo "mas bonito".

Hacerlo:

```txt
mas claro
mas guiado
mas seguro
mas consistente
mas vendible
mas dificil de usar mal
```

## Flujo validado que debe contar la UI

```txt
Empleado/Ficha apta
-> Preparar nomina
-> Resultado preliminar
-> Aprobacion operativa
-> Cierre operativo
-> Liquidaciones oficiales internas
```

## Prohibido

```txt
SQL
RPC
RLS
BD
formulas legales
motor de calculo
Previred real
LRE operativo
banco
contabilidad
PDF oficial
firma
envio
portal trabajador
reapertura

```
