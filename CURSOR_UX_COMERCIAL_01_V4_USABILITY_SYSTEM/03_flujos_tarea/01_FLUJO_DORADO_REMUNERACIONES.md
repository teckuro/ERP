# 01_FLUJO_DORADO_REMUNERACIONES

## Flujo principal

```txt
1. Ver Dashboard / estado del periodo
2. Ir a Preparar nomina
3. Validar periodo
4. Revisar bloqueos
5. Generar base
6. Calcular preliminar
7. Guardar resultado
8. Aprobar operativamente
9. Cerrar nomina
10. Ir a Liquidaciones oficiales
11. Generar/revisar liquidaciones
12. Ver detalle trabajador
```

## UI debe mostrar

En cada paso:

```txt
estado actual
accion principal
motivo si no se puede avanzar
accesos relacionados
```

## No debe exigir memoria

El usuario no debe recordar que despues de cerrar debe ir a Liquidaciones. La UI debe ofrecerlo.
