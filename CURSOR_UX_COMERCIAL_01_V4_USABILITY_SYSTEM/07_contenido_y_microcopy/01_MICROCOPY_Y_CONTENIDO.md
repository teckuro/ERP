# 01_MICROCOPY_Y_CONTENIDO

## Tono

```txt
claro
operativo
seguro
sin jerga tecnica
sin prometer futuro
```

## Mensajes para usar

### Error accion

```txt
No se pudo completar la accion. No se realizaron cambios parciales.
```

### Accion bloqueada

```txt
Esta accion no esta disponible porque {motivo}.
```

### Futuro

```txt
Disponible en una fase posterior.
```

### Tecnico

```txt
Detalle tecnico
```

## Reemplazos

```txt
snapshot -> resultado guardado
issues -> observaciones
hash -> identificador tecnico
RPC -> accion del sistema
```
