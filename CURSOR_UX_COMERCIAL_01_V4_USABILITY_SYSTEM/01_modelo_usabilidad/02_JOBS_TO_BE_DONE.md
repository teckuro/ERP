# 02_JOBS_TO_BE_DONE

## JTBD principal

Cuando estoy procesando remuneraciones de un periodo, quiero saber rapidamente que falta y cual es el siguiente paso para generar liquidaciones internas confiables sin cometer errores.

## Jobs por pantalla

### Preparar nomina

```txt
Cuando entro a Preparar nomina,
quiero ver el estado del periodo y la siguiente accion,
para avanzar sin revisar manualmente cada modulo.
```

### Movimientos del mes

```txt
Cuando no hay movimientos,
quiero saber si eso esta bien o si debo registrar algo,
para no omitir bonos, anticipos o descuentos del periodo.
```

### Asignaciones recurrentes

```txt
Cuando administro asignaciones,
quiero entender que se repite cada mes y que se carga solo una vez,
para no duplicar pagos o descuentos.
```

### Liquidaciones oficiales

```txt
Cuando la nomina esta cerrada,
quiero generar o revisar liquidaciones internas,
para confirmar lo que se pagara a cada trabajador.
```

### Detalle liquidacion

```txt
Cuando abro una liquidacion,
quiero ver haberes, descuentos y liquido claramente,
para responder dudas de un trabajador o revisar el resultado.
```

### Dashboard

```txt
Cuando abro el ERP,
quiero saber si el periodo esta al dia,
para decidir por donde partir.
```

## Criterio de diseno

Cada pantalla debe resolver su job principal antes de mostrar detalles secundarios.
