# Versionado normativo

Las normas laborales evolucionan con el tiempo y sus efectos deben registrarse de manera trazable.  Este documento mantiene un historial de vigencias para cada norma relevante y permite a los módulos del ERP consultar desde qué fecha aplicar determinadas reglas.  Cuando una norma pierde vigencia se registra la fecha de término; si la fecha está en blanco se entiende que continúa vigente.

Este cuadro es un ejemplo inicial y se ampliará con nuevas normas (asignación familiar, impuesto único, mutualidad, etc.).  Para cada entrada deben registrarse la vigencia inicial y, si corresponde, la vigencia final.  Cuando una norma es permanente se deja el campo en blanco.  Los módulos del ERP deben consultar esta tabla antes de validar o calcular datos que dependan de fechas.
