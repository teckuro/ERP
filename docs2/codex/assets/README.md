# Assets documentales

## Proposito

Carpeta para capturas, evidencias visuales y referencias usadas por documentacion `docs/codex`.

## Reglas

- No eliminar capturas historicas sin decision explicita.
- No mover archivos de evidencia si ya estan referenciados.
- Si existen varias versiones, documentar cual es vigente cuando se sepa.
- No guardar secretos, tokens, credenciales ni datos personales sensibles en imagenes.
- Si una fase cambia UI, registrar tambien en `../peticiones-estilos.md`.

## Estado 2026-05-10

Los assets existentes se consideran historicos utiles. La integracion documental no modifica imagenes.
