# Secuencia Visual para Formularios Basicos - ERP

## Objetivo

Definir una estructura estándar para TODOS los formularios del ERP,
evitando:

- espacios en blanco innecesarios
- grillas rígidas
- desorden visual
- formularios difíciles de leer

---

## 🧠 Principio base

👉 El formulario se organiza por SECUENCIA, no por grid global

---

## 1. Estructura obligatoria

Todo formulario debe seguir:

- 1 card principal
- múltiples secciones internas
- cada sección con su propia grilla

---

## 2. Patrón general

```text
Card principal
└── Sección 1
└── Sección 2
└── Sección 3
```
