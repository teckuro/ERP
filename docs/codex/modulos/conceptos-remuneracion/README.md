# Módulo Conceptos de remuneración — punto de entrada

## Estado

**Siguiente fase fuerte** del producto (pendiente de cierre en el tablero; p. ej. Fase 9). Debe definirse como **catálogo maestro** gobernado (LRE, sistema/protegido, automático/manual, vigencias) y **fuente** para haberes, descuentos, aportes y liquidaciones — sin mezclar con asignaciones por trabajador.
