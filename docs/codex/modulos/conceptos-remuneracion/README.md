# Módulo Conceptos de remuneración — punto de entrada

## Estado

**Pendiente de fase fuerte** (p. ej. Fase 9 en el tablero de producto). Debe definirse como **catálogo maestro** gobernado (LRE, sistema/protegido, automático/manual, vigencias) y **fuente** para haberes, descuentos, aportes y liquidaciones — sin mezclar con asignaciones por trabajador.
