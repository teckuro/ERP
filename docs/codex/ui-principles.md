# UI Principles

## Objetivo
Definir reglas base para diseño ERP profesional.

## Reglas

### 1. Bloque protagonista
Solo un elemento principal por pantalla.

### 2. Jerarquía visual
- Nivel 1: contenido principal
- Nivel 2: resumen / navegación
- Nivel 3: labels / ayudas

### 3. Layout estándar
HEADER → RESUMEN → CONTENIDO + SIDEBAR

### 4. Espaciado
Usar solo: 4 / 8 / 12 / 16 / 24 / 32 px

### 5. Formularios
Preferir una sola columna
