# Paleta de Colores - ERP Profesional

## Objetivo

Definir una paleta de colores moderna, profesional y consistente para todo el ERP.

Pensada para:

- uso prolongado (8+ horas)
- claridad visual
- bajo ruido
- estilo enterprise (tipo SAP / SaaS)

---

## 🎯 Principio base

👉 Menos colores = mejor UX  
👉 Colores suaves > colores saturados

---

# 🎨 1. Color primario (acción principal)

## Recomendado

Primary Blue:

#2563EB

---

## Uso

- botones primarios (Guardar)
- foco en inputs
- links activos
- selección

---

- hover: #1D4ED8

# 🚫 Qué evitar

❌ colores saturados (#FF0000, #00FF00)  
❌ múltiples tonos primarios  
❌ contrastes agresivos  
❌ fondos oscuros en ERP base

---

# 🎯 Resultado esperado

- interfaz limpia
- profesional
- fácil de usar
- sin fatiga visual

# 🧠 Regla final
