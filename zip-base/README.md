# ERP Remuneraciones Chile

Sistema ERP enfocado en cálculo de remuneraciones según normativa chilena 2026.

## Módulos

- Remuneraciones
- Contratos
- Previsión
- Liquidación de sueldos

## Stack

- Angular (frontend)
- PostgreSQL (Supabase)
- Node.js (futuro backend)
